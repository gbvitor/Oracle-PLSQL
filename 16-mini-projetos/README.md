# 16 — Mini-projetos

Projetos pequenos e completos, cada um em sua própria pasta, juntando modelagem, carga, regra de negócio em PL/SQL e testes.

Cada projeto traz um `README.md` com o enunciado, o modelo de dados, a ordem de execução dos scripts e os testes de aceite.

## Projetos planejados

- [ ] 01 — Controle de estoque: movimentações, saldo por produto e bloqueio de saldo negativo
- [ ] 02 — Biblioteca: empréstimos, devoluções, multa por atraso e reserva
- [ ] 03 — Faturamento simplificado: pedido, nota, parcelas e baixa de títulos
- [ ] 04 — Log e auditoria genéricos: package reutilizável de log com transação autônoma
- [ ] 05 — API em PL/SQL: package de cadastro com validação, exceções próprias e testes utPLSQL
