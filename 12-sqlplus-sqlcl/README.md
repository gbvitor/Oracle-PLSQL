# 12 — SQL*Plus e SQLcl

Os clientes de linha de comando do Oracle: execução de scripts, formatação de saída e recursos próprios do SQLcl.

## Tópicos

- [ ] 01 — Conexão: string de conexão, EZCONNECT, TNS, CONNECT e DISCONNECT
- [ ] 02 — Executar scripts: `@`, `@@`, START; parâmetros posicionais (&1, &2)
- [ ] 03 — Variáveis de substituição: `&`, `&&`, DEFINE, UNDEFINE, ACCEPT, SET VERIFY
- [ ] 04 — Bind variables: VARIABLE, PRINT, EXEC
- [ ] 05 — Formatação: SET LINESIZE, PAGESIZE, COLUMN FORMAT, HEADING, BREAK, COMPUTE
- [ ] 06 — SPOOL e geração de arquivos (CSV, relatório texto)
- [ ] 07 — Controle de erro em script: WHENEVER SQLERROR, WHENEVER OSERROR
- [ ] 08 — DESCRIBE, SHOW ERRORS, SHOW PARAMETER
- [ ] 09 — login.sql e glogin.sql
- [ ] 10 — SQLcl: SET SQLFORMAT, DDL, INFO, HISTORY, ALIAS, LOAD, UNLOAD, Liquibase
