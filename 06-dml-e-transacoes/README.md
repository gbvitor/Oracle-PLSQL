# 06 — DML e transações

Alteração de dados e controle de transação: o que fica visível para quem, quando os locks aparecem e como desfazer.

## Tópicos

- [ ] 01 — INSERT: valores, a partir de SELECT, várias linhas `[23ai+]` para VALUES múltiplo
- [ ] 02 — INSERT ALL e INSERT FIRST (inserção em várias tabelas)
- [ ] 03 — UPDATE: simples, com subquery, de várias colunas, via join (inline view atualizável)
- [ ] 04 — DELETE e TRUNCATE: diferenças
- [ ] 05 — MERGE: insert ou update numa só instrução; cláusula DELETE
- [ ] 06 — COMMIT, ROLLBACK e SAVEPOINT
- [ ] 07 — Commit implícito: DDL encerra a transação
- [ ] 08 — Consistência de leitura e UNDO
- [ ] 09 — Locks de linha e de tabela; quem está bloqueando quem
- [ ] 10 — Níveis de isolamento: READ COMMITTED e SERIALIZABLE
- [ ] 11 — DML error logging (LOG ERRORS)
