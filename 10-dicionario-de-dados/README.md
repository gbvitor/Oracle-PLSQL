# 10 — Dicionário de dados

Como descobrir a estrutura de um banco que você não conhece: tabelas, colunas, constraints, dependências e código-fonte, só com consultas.

## Tópicos

- [ ] 01 — Prefixos USER_, ALL_, DBA_ e CDB_; DICTIONARY

- [ ] 03 — Constraints e chaves: ALL_CONSTRAINTS, ALL_CONS_COLUMNS; montar o mapa de FKs
- [ ] 04 — Índices: ALL_INDEXES, ALL_IND_COLUMNS
- [ ] 05 — Objetos e código: ALL_OBJECTS, ALL_SOURCE, objetos inválidos
- [ ] 06 — Dependências: ALL_DEPENDENCIES (quem usa esta tabela?)
- [ ] 07 — Triggers: ALL_TRIGGERS e corpo do trigger
- [ ] 08 — Privilégios: USER_TAB_PRIVS, USER_SYS_PRIVS, ROLE_TAB_PRIVS
- [ ] 09 — Visões dinâmicas V$: V$SESSION, V$SQL, V$LOCK
