# 01 — Fundamentos

Conceitos que o resto do repositório pressupõe: como o Oracle organiza dados, quais tipos existem e como o NULL se comporta.

## Tópicos

- [ ] 01 — Modelo relacional: tabela, linha, coluna, chave primária, chave estrangeira, normalização
- [ ] 02 — Instância, banco, schema e usuário no Oracle (CDB/PDB)
- [ ] 03 — Tipos de dados: VARCHAR2, CHAR, NUMBER, DATE, TIMESTAMP, INTERVAL, CLOB, BLOB, RAW, BOOLEAN `[23ai+]`
- [ ] 04 — NULL: o que é, como se propaga em expressões, comparações e agregações
- [ ] 05 — DUAL e consultas sem tabela
- [ ] 06 — Pseudocolunas: ROWNUM, ROWID, LEVEL, SYSDATE, SYSTIMESTAMP, USER
- [ ] 07 — Identificadores: maiúsculas e minúsculas, aspas duplas, palavras reservadas, limite de tamanho
- [ ] 08 — Comentários em SQL e PL/SQL
- [ ] 09 — Ordem lógica de execução de um SELECT (por que um alias não funciona no WHERE)
- [ ] 10 — Categorias de comando: DQL, DML, DDL, DCL, TCL
