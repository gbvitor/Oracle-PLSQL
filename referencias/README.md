# Referências

Material de consulta rápida: a forma dos comandos, as máscaras de formato, os erros mais comuns e os termos. A explicação de cada item está na seção indicada.

| # | Referência | Conteúdo |
|---|---|---|
| 01 | [Folha de consulta de SQL](01-folha-sql.md) | SELECT e ordem lógica, joins, agregação e analíticas, subconsultas, hierarquia, DML, MERGE, transação, DDL, privilégios, plano, dicionário |
| 02 | [Folha de consulta de PL/SQL](02-folha-plsql.md) | Bloco, tipos, controle, cursores, exceções pré-definidas, procedures/functions/packages, triggers, coleções, BULK, SQL dinâmico, pacotes nativos, compilação |
| 03 | [Máscaras de formato](03-mascaras-de-formato.md) | Elementos de data, hora e número de `TO_CHAR`, `TO_DATE`, `TO_NUMBER`; modificadores `FM` e `FX`; NLS fixo na chamada; armadilhas |
| 04 | [Erros ORA- mais comuns](04-erros-ora.md) | Causa típica e correção, por grupo: sintaxe, conversão, integridade, consulta, trava, PL/SQL, objetos inválidos, privilégio, conexão, PLS- e SP2- |
| 05 | [Glossário](05-glossario.md) | Termos usados no repositório, com a seção de cada um |
