# 02 — Cláusulas

Cada cláusula do SELECT e dos comandos de manipulação, isolada: para que serve, a sintaxe completa e o que acontece em casos de borda.

## Tópicos

- [ ] 01 — SELECT e DISTINCT; aliases de coluna
- [ ] 02 — FROM: tabelas, aliases, inline views
- [ ] 03 — WHERE: filtros e ordem de avaliação
- [ ] 04 — GROUP BY: agrupamento simples, ROLLUP, CUBE, GROUPING SETS, GROUPING()
- [ ] 05 — HAVING: filtro sobre grupos; diferença para WHERE
- [ ] 06 — ORDER BY: múltiplas colunas, posição, NULLS FIRST / NULLS LAST, ordenação por expressão
- [ ] 07 — FETCH FIRST / OFFSET (top-N e paginação) e o equivalente com ROWNUM `[legado]`
- [ ] 08 — WITH (subquery factoring / CTE), inclusive WITH recursivo
- [ ] 09 — CONNECT BY, START WITH, PRIOR, SYS_CONNECT_BY_PATH, CONNECT_BY_ROOT
- [ ] 10 — PIVOT e UNPIVOT
- [ ] 11 — FOR UPDATE, NOWAIT, SKIP LOCKED, WAIT n
- [ ] 12 — RETURNING INTO em INSERT, UPDATE e DELETE
- [ ] 13 — SAMPLE e FLASHBACK QUERY (AS OF)
- [ ] 14 — MATCH_RECOGNIZE (reconhecimento de padrões em linhas)
- [ ] 15 — MODEL (visão geral)
